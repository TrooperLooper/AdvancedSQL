# Advanced SQL Backend Course

In this backend school project, I explored designing and building robust backend systems with advanced SQL (PostgreSQL), TypeScript, and modern engineering tools. I learned how to model complex data, write efficient queries, and create secure, scalable APIs using TypeScript and Node.js (Express). Along the way, I set up containerized development environments (Docker), automated code quality checks (ESLint, TypeScript), managed reliable database backups (SQL scripts), and tested APIs with Insomnia.
